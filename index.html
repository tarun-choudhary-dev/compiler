UNDER THE HOOD
From source to execution.

      
Real Python. Running right here in your browser.

      
A Python runtime, delivered to your browser.
Pyodide brings CPython, the reference implementation of Python, to the browser by compiling it to WebAssembly. The runtime loads once, then your code executes locally in a worker.
  1. Python source
  2. Pyodide
  3. CPython as WebAssembly
  4. Browser execution

      
Your source takes a different journey.
Python’s tokenizer identifies names, operators, strings and other tokens. Its parser builds an abstract syntax tree (AST). compile() turns the source into a code object with bytecode, which the Python virtual machine executes inside the WebAssembly runtime. Your source is not compiled directly into WebAssembly or native machine code.

  2. Tokens
  3. AST
  4. Code object

Tokens and AST
The Tokens tab reports actual tokenize output with positions. The AST tab shows the tree returned by ast.parse(), plus an optional full dump. Incomplete source can still yield partial tokens even when parsing fails.
Code object and bytecode
Inspect constants, names, local variables, stack size and flags from compile(). The Bytecode tab pairs decoded instructions with raw co_code bytes. Nested functions and classes have their own code objects.

      
Disassembly
Python’s dis module turns bytecode into readable operations, including nested code. Offsets, operation names and arguments describe CPython bytecode, not native processor instructions. Details vary by Python version.

      
A small, local workspace.
Each run starts with a fresh global namespace. Output and errors are captured separately. Stop ends the worker and resets Python. A 15-second execution limit and output limits keep everyday experiments manageable.
There is no interactive input or package installation in this version. Most of the bundled Python standard library is available. Runtime downloads need an internet connection; running your source does not use an execution API.

A TOOL FOR CURIOSITY
Meet Python, a little deeper.

      
PYLAB is a browser-based workspace for experimenting with Python execution and understanding its bytecode.

      
Write a few lines. Run them. Look at what CPython compiled. The editor, output, and inspection tools sit together so you can move between an idea and its implementation.
Built with CodeMirror and Pyodide. No accounts, no execution server, and no setup to start experimenting.
Your source stays in this page and its isolated runtime. The runtime receives no page APIs, and network requests from the execution environment are blocked. This is a learning tool, not a general-purpose hostile-code security sandbox.
